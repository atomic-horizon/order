AtomicPane

UI

The foundational model for all UI components in the game. Provides visibility controls, spring management, automatic alpha mapping, and more.

A VS Code snippet for creating AtomicPanes quickly is included with the Git repository.

NOTE

The source GUI objects should be located in ReplicatedStorage.GuiTemplates. They can be of any GuiObject type.

Basic usage

local AtomicPane = shared("AtomicPane") ---@module AtomicPane

local ExamplePane = setmetatable({}, AtomicPane)
ExamplePane.__index = ExamplePane
ExamplePane.ClassName = "ExamplePane"

function ExamplePane:_draw()
	local alpha = self._springs.Alpha.Position

	self.Gui.Visible = alpha < 0.999
end

function ExamplePane.new(parent: Instance)
	local self = setmetatable(AtomicPane.new("ExamplePaneTemplate", {}), ExamplePane)

	self:SetVisible(false, true)

	self.Gui.Parent = parent

	return self
end

return ExamplePane

MapAlpha​

</>
AtomicPane:MapAlpha(
element: Instance,--

The top-level instance to map transparencies for

exclusions: {Instance}?--

Instances whose subtrees are skipped, such as nested components that drive their own transparencies

) → ()

Caches the current transparency values of the specified instance and all its descendants in an internal table for automatic interpolation based on the Alpha spring, then draws them at the pane's current alpha.

The cached values are what each element shows when the pane is fully visible, so map elements while they look the way they should when visible.

UnmapAlpha​

</>
AtomicPane:UnmapAlpha(
element: Instance--

The top-level instance to stop driving

) → ()

Stops driving the specified instance and its descendants from the Alpha spring. Their transparencies are left as they are, for when another animation takes them over.
