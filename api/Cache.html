Cache

A named cache object returned by CacheService:CreateCache(). Stores key-value pairs with an age limit and entry limit.

Functions​

</>

index: any--

Returns the cached value at the given index, or nil if the entry is missing or expired.

GetOrAdd​

This is a yielding function. When called, it will pause the Lua thread that called the function until a result is ready to be returned, without interrupting other scripts. Yields
</>
Cache:GetOrAdd(
index: any,--

The cache key to look up

addCallback: AddCallback--

Called to produce the value if not cached

) → any?--

The cached or newly produced value

Returns the cached value at the given index. If it is missing or expired, calls addCallback to produce a value, caches it, and returns it.

Only one addCallback runs per index at a time. Callers that arrive while a value is being produced wait for that result instead of producing their own. If addCallback errors, every waiting caller receives the error and nothing is cached.

addCallback may return a cleanup function as a second value, which runs once when the entry is removed, replaced, or expires.
