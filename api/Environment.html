Environment

Answers which environment the current place runs in. A place's environment is set by its entry in Settings.PlaceTypes: 

PlaceTypes = {
	[123456789] = "Lobby", -- Production
	[987654321] = { Type = "Lobby", Environment = "Testing" },
},

Functions​

GetName​

</>
Environment.GetName() → EnvironmentName

Returns the environment set for this place in Settings.PlaceTypes. Places without one are "Production". This does not account for Studio; see IsProduction for that.

IsProduction​

</>
Environment.IsProduction() → boolean

Whether this is a live server of a production place. False in Studio and in places marked "Testing".

IsTesting​

</>
Environment.IsTesting() → boolean

Whether this runs in a place marked "Testing" or in Studio.

UsesMockData​

</>
Environment.UsesMockData() → boolean

Whether data stores are replaced with in-memory mocks, through the UseMockData attribute on workspace. Nothing is saved while this is on. Always false in live production servers.

UsesReadOnlyData​

</>
Environment.UsesReadOnlyData() → boolean

Whether saved data is loaded but never written, through the ReadOnlyData attribute on workspace. Data loads from the store this place would normally use, and changes made during the session are discarded, so a test can start from the same saved state every time. Always false in live production servers.
