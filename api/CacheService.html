CacheService

Simple module for caching any data.

Produces a value to cache. It may return a cleanup function as a second value, which runs once when the entry leaves the cache.

GetOrAdd​

This is a yielding function. When called, it will pause the Lua thread that called the function until a result is ready to be returned, without interrupting other scripts. Yields
</>
CacheService:GetOrAdd(
cacheName: string,--

The name of the cache

index: any,--

The cache key to look up

addCallback: AddCallback--

Called to produce the value if not cached

) → any?

Returns the cached value at the given index. If missing or expired, calls addCallback to produce a value, caches it, and returns it. See Cache:GetOrAdd for details.

Remove​

</>
CacheService:Remove(
cacheName: string,--

The name of the cache

index: any--

The cache key to remove

) → ()

Removes a value from the named cache right away and runs its cleanup. Values are also removed automatically when they expire or when the cache exceeds its entry limit.
